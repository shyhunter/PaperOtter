Your local document toolkit

Compress, convert, sign and edit PDFs, images and documents: on your own machine, without an account and without an internet connection.

Download Source on GitHub

Free and open source · macOS, Windows and Linux

Your files never leave your computer.

No uploads, no cloud processing, no accounts, no telemetry. Papercut makes exactly two network requests, neither carrying anything about you or your documents: it checks GitHub for a newer version on launch, and fetches a contact address when you open the About window. That is the whole list.

What it looks like

Pick a tool, choose a file, see the result before you save it. Nothing is written until you say so, and saving over your original is always a deliberate choice.

Download

One installer, everything included. Ghostscript is bundled: there is nothing else to fetch.

PlatformFileNotes
macOS (Apple silicon) .dmg Unsigned for now: macOS may say the app is damaged. Open System Settings → Privacy & Security and choose Open Anyway.
Windows .exe installer SmartScreen may warn. Choose More info, then Run anyway.
Linux .AppImage or .deb Nothing extra to accept.

Those warnings appear because the app is not yet signed with a paid certificate, not because anything is wrong with the download. The release page lists checksums for every file.

Worth knowing before you download

The things a download page usually leaves out.

One tool needs help

Converting to EPUB or MOBI uses Calibre, and some document formats use LibreOffice. Everything else (all twenty-one other tools) runs with nothing installed.

Two features are macOS-only

Reading text from scans uses Apple's built-in engine, and HEIC photos need a decoder the operating system licenses. Papercut hides what it cannot run rather than offering it and failing.

Nine languages, one native

Only the English is written by a native speaker. The rest are machine-assisted and unreviewed. Warnings about losing files are translated everywhere or nowhere, never half-done. Corrections are very welcome.

It is a young project

Built by one person. If something breaks, the issue tracker is read by the person who wrote the code, and bugs reported there are what shaped most of what is here.
