## What's new in 1.0.1

A bug-fix release. If 1.0.0 works for you, nothing changes except the two fixes below.

- **Linux AppImage now starts in sandboxes.** In 1.0.0 one file inside the AppImage could only be run by its owner, so starting PaperOtter inside firejail, or anything else that runs it as a different user, closed it immediately with `AppRun.wrapped: Permission denied`. Every file inside is now runnable, and the release pipeline checks this before publishing.
- **Compress gives the right reason for protected PDFs.** Many published PDFs (annual reports, statements) open without a password but are protected against changes. Compress still leaves them alone, since compressing would strip that protection, but it now says so instead of claiming the file is password-protected. Translated into all nine languages. (#8)
