## What's new in 1.0.2

A security and maintenance release. There are no new features, but **macOS 12 Monterey and older are no longer supported** (see below).

### Security fixes

- **rustls 0.23.46** fixes RUSTSEC-2026-0346, -0347, -0348 and -0349, and **quinn-proto 0.11.19** fixes RUSTSEC-2026-0338, -0340 and -0343. **rustls-webpki 0.103.16** and **webpki-roots 1.0.10** fix RUSTSEC-2026-0382 and -0381, which let certificate checks accept intermediates from emSign that are no longer trusted. All four sit under the HTTPS client PaperOtter uses for its only two network requests: checking GitHub for a newer version, and fetching where the Feedback button points. PaperOtter itself sends nothing about your documents. All platforms.
- **Converting with Microsoft Word (macOS and Windows):** the full path of your document was written into the script that drives Word, and only the file name was checked. A folder with a crafted name could make that script run commands of its own. Paths now reach Word as data and are never part of the script.
- **HTML to PDF (macOS):** scripts inside the HTML file no longer run while PaperOtter renders it. A page that builds its content with JavaScript will convert as its plain HTML.
- **Update notice:** the "Update available" button now only opens PaperOtter's own release pages on github.com over https, the same rule the Feedback link already follows. Anything else opens the main releases page.
- **Linux only:** glib is patched for RUSTSEC-2024-0429.

### macOS now needs 13 Ventura, kept up to date

PaperOtter now uses pdf.js 6 to show PDFs, and pdf.js 6 needs the Safari 18 engine. Safari 18 is available for macOS 13 Ventura and newer, but not for Monterey, so PaperOtter 1.0.2 needs macOS 13 Ventura, kept up to date. On macOS 12 or older, macOS will now refuse to open 1.0.2 rather than let it start with PDF previews broken. Keep using 1.0.1 there, or update macOS. On Ventura, install the latest Safari from Software Update if PDFs don't display.

Windows and Linux requirements are unchanged.

### Under the hood

- Tauri 2.12 (JavaScript and Rust sides together).
- pdf.js 6, which releases each document more cleanly when you close it or open another one.
- A smaller dependency tree: unused image codecs (AVIF and the rayon thread pool) were dropped from the build.
