## What's new in 1.0.2

A security and maintenance release. There are no new features, but **macOS 12 Monterey and older are no longer supported** (see below).

### Security fixes

- **rustls 0.23.46** fixes RUSTSEC-2026-0346, -0347, -0348 and -0349, and **quinn-proto 0.11.19** fixes RUSTSEC-2026-0338, -0340 and -0343. Both sit under the HTTPS client PaperOtter uses for its only two network requests: checking GitHub for a newer version, and fetching where the Feedback button points. Your documents never go over the network. All platforms.
- **Linux only:** glib is patched for RUSTSEC-2024-0429.

### Minimum macOS is now 13 Ventura

PaperOtter now uses pdf.js 6 to show PDFs, and pdf.js 6 needs the Safari 18 engine. Safari 18 is available on macOS 13 Ventura and newer, but not on Monterey. On macOS 12 or older, macOS will now refuse to open 1.0.2 rather than let it start with PDF previews broken. Keep using 1.0.1 there, or update macOS. On Ventura, install the latest Safari from Software Update if PDFs don't display.

Windows and Linux requirements are unchanged.

### Under the hood

- Tauri 2.12 (JavaScript and Rust sides together).
- pdf.js 6, which releases each document more cleanly when you close it or open another one.
- A smaller dependency tree: unused image codecs (AVIF and the rayon thread pool) were dropped from the build.
